# nMedium

nMedium is an app for browsing a media server's library and controlling its playback, on Android or in a browser.
It works with [JRiver Media Center](https://jriver.com/), and can play on the server's zones or on the phone or
browser you're using.

This repository is nMedium's public issue tracker. The source code is not public.

## Reporting a problem or suggesting a feature

[Open an issue](https://github.com/GrantDG/nMedium/issues/new/choose) and pick **Bug report** or
**Feature request**. Before you do, please search the
[existing issues](https://github.com/GrantDG/nMedium/issues?q=is%3Aissue) in case someone has already raised it;
if so, add a 👍 or any extra detail there.

A good bug report says what you did, what you expected and what happened instead, and which device, version and
media server you were using. Screenshots or a short screen recording help a lot.

Issues are public, so please don't include passwords, access keys or your server's public address.

## What happens next

New issues are labelled `triage` until they've been looked at. If more detail is needed, you'll be asked in the
issue. When a fix or feature is done, the issue is closed with a note saying which release it's in.
